# Gerador-de-Senhas
## funcionalidades:
- Geração instantânea de senhas;
- Escolha do número de caracteres (4 a 32)-
- Inclusão de: letra maiúscula, letra minúscula simbolos e números;
- Barra indicativa da força da senha;
- interface responsiva;
- Atualização automatica da senha sempre que uma configuração é alterada.

- ## Responsividade
- O projeto foi desenvolvido para funcionar em diferentes tamanhos de tela, oferecendo uma boa experiência tanto em computadores quando em dispositivos moveis.

- ## Objetivo do projeto
- Esse projeto foi desenvolvido com fins educacionais para praticar conceitos de desenvolvimento front-end, incluindo:
- Eventos em Java Script;
- Organização de códigos;
- Geração aleatória de caracteres;
- Responsividade com CSS;
